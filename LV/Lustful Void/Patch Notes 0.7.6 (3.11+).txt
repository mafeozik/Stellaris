LV v0.7.6.0 (for game version 3.11+)

(-- Notes --)

This update focuses mainly on updating old code and a general balance pass to align better 
with base game systems. This process takes a while and will be completed over multiple 
updates.

Irony versions have been removed as they are no longer needed.

The next dlc will give me an excuse to finally make those cybernetics traits I've wanted
to make! If you have any ideas for cybernetics, feel free to share :)
